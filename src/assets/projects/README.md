# Imágenes de proyectos

Suelta aquí las capturas y listo: se detectan automáticamente por nombre de archivo.
No hay que editar código ni frontmatter.

## Nombres esperados

| Archivo | Proyecto |
|---|---|
| `auditor-ia-rag.*` | Auditor IA · Tesis |
| `vacacional.*` | Vacacional Los Nanos |
| `moviliza2.*` | Moviliza2 |
| `ayre-web.*` | Centro AYRE |
| `notificaciones-whatsapp.*` | Recordatorios por WhatsApp |
| `crm-eclipttica.*` | CRM Eclipttica |

Extensiones válidas: `.png`, `.jpg`, `.jpeg`, `.webp`, `.avif`.

## Recomendaciones

- Proporción **16:9 o 16:10** (se recortan con `object-fit: cover`).
- Ancho mínimo **1600 px** para que se vean nítidas en pantallas grandes.
- Formato `.webp` o `.jpg` para mantener el sitio rápido.
- Si un proyecto no tiene imagen, se muestra el placeholder generado por el sitio.
