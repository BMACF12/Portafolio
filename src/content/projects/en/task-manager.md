## Context

A web app for daily task management focused on personal productivity and small teams.

## Technical challenges

- Real-time sync across multiple clients without state conflicts.
- Offline-first support with conflict resolution on reconnect.
- Full accessibility: keyboard navigation, screen readers and AA contrast.

## What I learned

Shared real-time state requires thinking about the data model before the UI. RxJS allowed modeling change flows as declarative streams.
