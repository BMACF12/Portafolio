## Context

Second version of my personal portfolio: from static HTML to a modern application with Astro, strict TypeScript and cinematic animations.

## Technical challenges

- Horizontal "deck" scroll synchronized with vertical scroll via ScrollTrigger.
- Animation system respecting `prefers-reduced-motion` at every level.
- i18n without heavy external libraries: JSON + typed helpers.

## What I learned

Quality animation is not about quantity of effects, but choreography: a single RAF loop, GPU-only transforms and transitions with narrative purpose.
